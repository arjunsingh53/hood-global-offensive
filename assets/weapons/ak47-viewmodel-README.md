# HGO AK-pattern first-person model

`ak47-viewmodel.glb` is an original, project-authored low-poly first-person
rifle model. It was generated by
[`tools/build_ak47_viewmodel.py`](../../tools/build_ak47_viewmodel.py), rather
than copied from Call of Duty, another game, a weapon library, or the web.

The model intentionally has a readable AK-pattern silhouette at first-person
distance: a separate stamped receiver and top cover, gas tube, front/rear
sights, barrel/muzzle device, layered wood furniture, pistol grip, curved
stamped magazine, selector, charging handle and receiver hardware. It is a
presentation asset only; its GLB has no gameplay, collision, damage, recoil,
ammo, progression, firing or input data.

## Rebuilding

From the checkout, run the script through the bundled Blender installation:

```powershell
& 'F:\WORK\cli-gui\.tooling\blender-5.2.2\blender-5.2.2-windows-x64\blender.exe' `
  --factory-startup --disable-autoexec --background --python `
  tools\build_ak47_viewmodel.py -- assets\weapons\ak47-viewmodel.glb
```

The runtime contract is `+X` along the rifle, muzzle at `-X`, glTF `+Y` up,
and `+Z` side. `WeaponModels` measures those bounds at load time, scales the
barrel to the view-model pose, and derives the muzzle flash point from the
front mesh slice. The same canonical orientation allows a future third-person
holder integration to start from the same asset, but that integration must
still validate hand contact and animation independently.

Current generated asset: 37 meshes; 2,611 Blender-export triangles (5,348 as
loaded by Raylib after primitive processing); source bounds loaded by Raylib
are `2.400 × 1.246 × 0.440` and its measured muzzle is
`(-1.477, 0.261, 0.000)`.
